# Restaurant-Order-Analysis
This SQL project analyzes a restaurant database (restaurant_db) consisting of two tables: menu_items (menu catalog, categories, and pricing) and order_details (granular customer transaction logs). The goal is to evaluate menu performance, monitor operational transaction volumes, and uncover the purchasing habits of high-value customers.
